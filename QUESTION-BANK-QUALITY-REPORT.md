# GK Swal question-bank quality report

- Target: 12 categories × 400 questions = 4,800 total questions.
- The supplemental CSV contains 3483 rows. Existing questions in the app are intended to fill the per-category gaps.
- Rebuilt the four options for each supplemental question using answer pools from the same category and a simple question-type heuristic.
- This reduces clearly unrelated cross-category distractors but is not a substitute for a human factual review.
- Current Affairs contains historical/static examples as well as time-sensitive content; it must be refreshed and date/source checked before public release. Use official sources such as PIB, RBI, Election Commission, ISRO, and relevant ministry sites.
- Do not advertise the full 4,800 as independently fact-checked until that review and Android runtime tests are complete.
