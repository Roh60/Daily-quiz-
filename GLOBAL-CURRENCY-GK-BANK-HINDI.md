# Global Currency GK Question Bank

- **Total:** 2,003 four-option MCQs bundled in the Android app.
- Country/territory currency mappings considered: 248.
- Distinct ISO currency codes represented: 152.
- Topics: country → currency, country → ISO code, currency name → ISO code.
- Includes 3 separate examples in the requested style: India currency name, $1 = ₹96 and €1 = ₹108. The two rate values are explicitly labeled user-supplied practice examples, not current exchange rates.
- Every question has four distinct options, a correct answer index, and an explanation.
- Android asset: `app/src/main/assets/global_currency_gk_questions.json`.
- CSV export: `global-currency-gk-questions.csv`.
- Separate fact-check tracker: `global-currency-gk-fact-check-tracker.csv` (all rows currently UNVERIFIED).

## Accuracy note

The bank was generated from country/currency metadata available through Babel/CLDR and ISO-style codes. It is a useful initial practice bank, not a claim that every country/territory nuance has been independently human fact-checked. Currency arrangements can have exceptions, multiple legal-tender currencies, or geopolitical changes. The three exchange-rate-style sample questions use values supplied as examples and must not be represented as current rates.
